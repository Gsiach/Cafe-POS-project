## Project Overview

This project develops a Point of Sale (POS) system for a small cafe restaurant,
following Craig Larman's Unified Process methodology. The system covers order
management, payment processing, inventory tracking, and sales reporting for both
counter and dine-in service.

## Document Rationale (Inception Phase Structure)

Each document was deliberately structured as follows:

- **01_Project_Context** — Merged introduction and business context. Covers
  both the "Who" and the "Where" of the project in a single strong opening.

- **02_Problem_Statement_and_Business_Case** — Merged problem statement and
  business case. Links the pain point directly to the ROI justification.

- **03_Vision_Scope_and_Stakeholders** — Scope defined alongside stakeholders
  so user roles can be cross-referenced against project boundaries.

- **04_High_Level_Requirements** — Core functional and non-functional
  requirements, use case model, and main actors.

- **05_Risk_Analysis_and_Feasibility_Study** — Feasibility and risk combined.
  Evaluates what is possible while identifying what might go wrong.

- **06_Iteration_and_Project_Plan** — Timeline of major milestones and UP
  phase breakdown.

- **07_Conclusion** — GO/NO-GO recommendation and final viability assessment.

- **08_Glossary** — Project data dictionary. Defines key domain terms used
  across all documents.
