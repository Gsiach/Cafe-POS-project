<h2>Project Plan – Cafe Small Restaurant POS System</h2>

<h3>1. Development Approach</h3>
<p>
The project will follow the <strong>Unified Process (UP)</strong> lifecycle, consisting of four main phases:
</p>

<ol>
  <li>Inception</li>
  <li>Elaboration</li>
  <li>Construction</li>
  <li>Transition</li>
</ol>

<p>
Development will be iterative, with incremental refinement of requirements, design, and implementation.
</p>

<hr>

<h3>2. Phase Breakdown and Activities</h3>

<table border="1" cellpadding="8" cellspacing="0">
  <thead>
    <tr>
      <th>Phase</th>
      <th>Objective</th>
      <th>Activities</th>
      <th>Deliverables</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>Inception</strong></td>
      <td>Define project scope, vision, feasibility, and major risks.</td>
      <td>
        <ul>
          <li>Identify stakeholders</li>
          <li>Define business context and problem statement</li>
          <li>Develop vision and scope</li>
          <li>Identify high-level requirements</li>
          <li>Create high-level use case model</li>
          <li>Conduct feasibility and risk analysis</li>
          <li>Prepare initial project plan</li>
        </ul>
      </td>
      <td>
        <ul>
          <li>Inception documentation</li>
          <li>High-level use case diagram</li>
          <li>Risk analysis</li>
          <li>Business case</li>
        </ul>
      </td>
    </tr>

    <tr>
      <td><strong>Elaboration</strong></td>
      <td>Refine requirements and establish system architecture.</td>
      <td>
        <ul>
          <li>Expand detailed use cases</li>
          <li>Define system architecture</li>
          <li>Identify database structure</li>
          <li>Address high-priority risks</li>
          <li>Create architectural prototype</li>
        </ul>
      </td>
      <td>
        <ul>
          <li>Detailed use case specifications</li>
          <li>Software architecture document</li>
          <li>Updated risk assessment</li>
        </ul>
      </td>
    </tr>

    <tr>
      <td><strong>Construction</strong></td>
      <td>Develop and test the system.</td>
      <td>
        <ul>
          <li>Implement core functionalities (Process Sales, Inventory Management, Reporting, Staff Management)</li>
          <li>Conduct unit and integration testing</li>
          <li>Refine user interface</li>
          <li>Perform system testing</li>
        </ul>
      </td>
      <td>
        <ul>
          <li>Functional POS system</li>
          <li>Test reports</li>
          <li>Updated documentation</li>
        </ul>
      </td>
    </tr>

    <tr>
      <td><strong>Transition</strong></td>
      <td>Deploy and validate the system in a real or simulated environment.</td>
      <td>
        <ul>
          <li>System deployment</li>
          <li>User training</li>
          <li>Bug fixing and final adjustments</li>
          <li>Final evaluation</li>
        </ul>
      </td>
      <td>
        <ul>
          <li>Deployed system</li>
          <li>User manual</li>
          <li>Final project report</li>
        </ul>
      </td>
    </tr>
  </tbody>
</table>
