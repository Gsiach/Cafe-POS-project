<h1 align = "center">Iteration Plan – Café POS System</h1>

The Café POS System will follow an iterative and incremental development approach. Each iteration will deliver a working version of the system with increasing functionality and refinement.


<h2>Iteration 1: Requirements & System Foundation (Inception Phase)</h2>
Duration: Week 1 – Week 2
Objectives:
<ul>
  <li>Identify system stakeholders.</li>
  <li>Gather and document functional and non-functional requirements.</li>
  <li>Define system vision and scope.</li>
  <li>Create initial system architecture design.</li>
  <li>Develop use case diagrams and system models.</li>
</ul>
Deliverables:
<ul>
  <li>Vision & Scope Document</li>
  <li>Use Case Diagram</li>
  <li>Software Requirements Specification (SRS)</li>
  <li>Initial Database Design</li>
</ul>



<h2>Iteration 2: Core Sales Module Development</h2>
Duration: Week 3 – Week 4
Objectives:
<ul>
  <li>Develop user authentication (Admin, Manager, Cashier).</li>
  <li>Implement product management (Add, Edit, Delete items).</li>
  <li>Develop order processing module.</li>
  <li>Implement automatic total calculation.</li>
  <li>Generate digital receipts.</li>
</ul>
Deliverables:
<ul>
  <li>Working Sales Processing System</li>
  <li>Login & Role-Based Access Control</li>
  <li>Functional POS Interface</li>
</ul>


<h2>Iteration 3: Inventory & Reporting Module</h2>
Duration: Week 5 – Week 6
Objectives:
<ul>
  <li>Implement inventory tracking system.</li>
  <li>Auto-update stock after each sale.</li>
  <li>Add low-stock alert system.</li>
  <li>Generate sales reports (Daily, Weekly, Monthly).</li>
  <li>Implement transaction history storage.</li>
</ul>
Deliverables:
<ul>
  <li>Inventory Management Module</li>
  <li>Reporting Dashboard</li>
  <li>Data Analytics Overview</li>
</ul>


<h2>Iteration 4: Testing, Optimization & Deployment</h2>
Duration: Week 7 – Week 8
Objectives:
<ul>
  <li>Perform system testing (Unit, Integration, System Testing).</li>
  <li>Fix bugs and improve performance.</li>
  <li>Improve user interface and usability.</li>
  <li>Prepare final documentation.</li>
  <li>Deploy final version.</li>
</ul>
Deliverables:
<ul>
  <li>Fully Tested POS System</li>
  <li>Test Report</li>
  <li>Deployment Package</li>
  <li>Final Project Documentation</li>
</ul>
